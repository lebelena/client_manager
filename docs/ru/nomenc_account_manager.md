# Справочник «Номенклатура»

{% note info %}

**Группа номенклатур** — справочник клиентских характеристик, требуемых для описания товара.

**Номенклатура** — сводный перечень общих характеристик, необходимый для описания товара или оборудования.

{% endnote %}

При переходе в подсистему на странице отображается список добавленной ранее номенклатуры. 
Список номенклатуры зависит от выбранной группы. По умолчанию отображается вся добавленная номенклатура. Если выбрать группу, она выделится зелёным, а в списке останутся позиции, относящиеся к только к этой группе.

![_screen_nomenc](_images/_screen_nomenc_start_page.png){.center width=1200}

Можно кликнуть по любому элементу списка, чтобы просмотреть подробную информацию по конкретной номенклатуре. Также на странице **можно добавить новую номенклатуру или изменить существующую.**  

{% note warning %}

**Удалить номенклатуру нельзя**, но можно изменить информацию об уже внесенной. 

{% endnote %}

## Добавление номенклатуры

Номенклатура добавляется по команде «Добавить», расположенной над списком номенклатуры. Если в момент добавления выбрана определённая группа, номенклатура автоматически отнесётся к ней.

![_modules_about](_images/nomenc_add.png){.center width=1200}

**У любой номенклатуры необходимо заполнить обязательные поля**: наименование и артикул. 

Рекомендуется заполнить поля с информацией о характеристиках упаковки, в которой поставляется номенклатура, поле страховой стоимости, а также прикрепить фото номенклатуры и связанные с ней файлы. 

После заполнения всех полей нажмите кнопку «Добавить».

![_screen_nomenc](_images/_screen_card_nomenc.png){.center width=1200}

## Редактирование номенклатуры

**Чтобы отредактировать номенклатуру,** нажмите на нужную позицию номенклатуры в списке и в карточке номенклатуры кликните «Редактировать».

![_screen_nomenc](_images/_screen_card_nomenc_edit.png){.center width=1200}

В открывшемся модальном окне можно заменить фото и прикреплённые файлы, изменить наименование или артикул, изменить существующую или добавить новую конфигурацию упаковки с помощью кнопки «Новая конфигурация». 

![_modules_about](_images/screen_edit_2.png){.center width=1200}

Когда вы добавите несколько конфигураций, в окне появятся вкладки. Переключаясь между ними, вы будете видеть характеристики упаковки для каждой конфигурации.

![_modules_about](_images/screen_edit_3.png){.center width=1200}
