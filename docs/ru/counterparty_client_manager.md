# Контрагенты

В данной подсистеме отображаются контрагенты, с которыми вы можете взаимодействовать:
- вы;
- контрагент, в интересах которого вы выполняете работу (например, Юнилевер или Пепси);
- работодатель, с которым у вас есть заключенный договор (например, ПОСМ.РЦ или Паблик Тотем).

![_screen_task_warehouse_nomec](_images/counterparty_list.png){.center width=1200}

При клике по контрагенту из списка можно просмотреть общую информацию, информацию о договорах, а также о банковских реквизитах и пространствах.  

![_screen_task_warehouse_nomec](_images/counterparty_show.png){.center width=1200}

{% note warning %}

**Карточка контрагента доступна только для просмотра:** редактирование и деактивация недоступны.
Если вы заметили несоответствие отображдаемой информации с фактической, необходимо обратиться к HR-менеджеру для внесения изменений. 

{% endnote %}
